# Wiki Guide

## Purpose

- Teach users how to install, configure, and operate CSI through progressive, task-oriented documentation.

## Ownership

- Wiki navigation in `Home.md`, `INDEX.md`, and `README.md`.
- Numbered user guides and `WIKI_ROADMAP.md`.

## Local Contracts

- Configuration syntax, action names, paths, and behavior must be verified against current source and root references.
- Keep navigation links relative and update all three navigation surfaces when adding, renaming, or removing a page.
- Distinguish completed documentation from roadmap-only material.

## Work Guidance

- Lead with user goals and tested examples; introduce internal architecture only when it helps the task.
- Keep terminology consistent with the plugin UI, zone files, surface templates, and root reference documents.
- Remove stale status claims and dates when they no longer describe the repository.

## Verification

- Check all relative links and referenced filenames.
- Validate command/configuration examples against current source or a working REAPER setup.
- Review `Home.md`, `INDEX.md`, and `README.md` together after navigation changes.

## What is CSI?

The **Control Surface Integrator (CSI)** is a Reaper plugin that enables seamless integration of hardware control surfaces (MIDI controllers, MCU devices, OSC tablets) with Reaper. CSI provides:

✅ **Multi-surface support** - Combine MIDI, MCU, and OSC devices  
✅ **Deep Reaper control** - Access to 100+ actions  
✅ **FX parameter mapping** - Control any plugin parameter  
✅ **Highly customizable** - Text-based configuration files  
✅ **Cross-platform** - Windows, macOS, Linux  

---

## Key Features

| Feature | Description |
|---------|-------------|
| **Multiple Surfaces** | Integrate MIDI, MCU, and OSC devices simultaneously |
| **Flexible Zones** | Define different control layouts for different tasks |
| **FX Mapping** | Auto-map or manually map plugin parameters to controls |
| **Modifiers** | Use Shift, Control, Alt, Touch, and custom modifiers |
| **Track Navigation** | Bank through tracks with intelligent scrolling |
| **Display Feedback** | Show parameter values on device displays |
| **Color Support** | LED color feedback on compatible devices (X-Touch, etc.) |
| **OSC Support** | Use phones, tablets, or networked devices |
| **JSFX Support** | Control ReaJS plugins |

## Core Architecture

```
CSI System
├── Pages
│   ├── Surface Configuration (surface.txt)
│   ├── Zones (.zon files)
│   │   ├── Track Zones
│   │   ├── FX Zones

│       ├── MIDI Device
│       ├── MCU Device
│       └── OSC Device
└── Actions (100+ available)
    ├── Transport (Play, Stop, Record)
    ├── Track Control (Volume, Pan, Mute, Solo)
    ├── FX Mapping (Parameter control)
    ├── Navigation (Zone switching, Banking)
    └── Display (Feedback to surface)
```

## How CSI Works: Basic Flow

```
1. User presses hardware control
   ↓
2. Hardware sends MIDI/OSC message
   ↓
3. CSI receives message in active Zone
   ↓
4. Zone file maps message to CSI Action
   ↓
5. Action updates Reaper (e.g., changes volume)
   ↓
6. Reaper sends data back to CSI
   ↓
7. CSI updates hardware display/LED feedback
```

## Important Notes

⚠️ **MIDI Ports Must Be Disabled**: CSI requires exclusive access to MIDI ports. You must disable MIDI ports for your controllers in Reaper's Preferences.

ℹ️ **Text-Based Configuration**: CSI uses plain text files (.zon, surface.txt) for configuration. This makes it powerful but requires attention to detail.

💡 **Learning Curve**: The first zone can take time to understand, but subsequent zones become faster.
